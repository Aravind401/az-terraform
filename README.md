# az-terraform

This repository contains standalone Terraform configurations for Azure:

- [network](./network/README.md): virtual network and purpose-specific subnets.
- [webapp](./webapp/README.md): Linux App Service Plan and Node.js Web App.
- [functionapp](./functionapp/README.md): Linux Function App, storage account, and Node.js runtime.
- [containerapp](./containerapp/README.md): Container Apps environment and containerized app.
- [containerregistry](./containerregistry/README.md): Azure Container Registry.
- [postgresql](./postgresql/README.md): Azure Database for PostgreSQL Flexible Server and database.
- [kubernetes](./kubernetes/README.md): Azure Kubernetes Service (AKS) cluster.
- [servicebus](./servicebus/README.md): Azure Service Bus namespace and queue.
- [rediscache](./rediscache/README.md): Azure Managed Redis cache.
- [keyvault](./keyvault/README.md): Azure Key Vault configured for Azure RBAC authorization.
- [managedidentity](./managedidentity/README.md): user-assigned managed identity.
- [storageaccount](./storageaccount/README.md): secure-by-default Azure Storage Account.
- [vm](./vm/README.md): Ubuntu ARM64 virtual machine (`Standard_B2ats_v2`) with SSH restricted by source CIDR.
